PROCESS descriptor resolution call-site inventory (#895 / #933)
==============================================================

Non-invasive source audit. No descriptor API is implemented or accepted by
this document. Upstream baseline197d05ce6d71efb8e626df5b4e7db11d29f5c3fc;
filesystem-owner overlay inspected separately at0789321f0960a7112198fc08a59b093cb0419cdc.
Line anchors below refer to the epic baseline unless explicitly marked #933;
function names identify sites when owner changes move line numbers. The fork
validation605a4ab79 does not import #933. Existing kernel/legacy namespaces
must be preserved until a coherent owner-reviewed migration is ready.

Reproduce the initial census at the baseline with:
  rg -n 'sft\[|syshnd\(|PD_UFT\(|getofd\(|getpfsslot\(' bdos fs
Also inspect raw handle arithmetic, indirect close/backing operations and
macros in fs.h/pfs.h. A text match is not proof that a site handles user-local
numbers: internal raw slots must stay distinguishable from public descriptors.

Includes/constants: bdos/fsglob.c defines SFT storage; bdos/fs.h defines FTAB
and limits; fs/pfs.h documents native/foreign cookie handling. Audit these
representations without converting private backend indices into user handles.

Migration acceptance
--------------------
A resolver-only patch is insufficient because R05, A04/A06 and B03/B04 bypass
or reinterpret it. The owner must define internal-reference versus local-handle
boundaries before staged activation. One coherent gate must migrate every
managed PROCESS creation/lookup/operation/retirement path, while legacy
non-ASPACE uses its existing implementation. No fork-only table. Source
binding admission must reject reentrant close/rebind while copying its owned
prefix and must not reuse the irreversible retirement latch.

Checked acquire/expected-incarnation release and implementation ownership are
still awaiting the #933 owner's explicit decision. This audit authorizes no
SFT-counter, ticket, cleanup or callback policy changes.
