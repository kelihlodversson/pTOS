Phase 3 completion audit (#892)
===============================

Integration baseline: 6ebabf7c0d73b7c41472a659cefa85ddf175ef11.
Candidate changes: prepared root-group THREAD construction now uses the common
LOADED_PROCESS/PREPARED_VM factory; native first-instruction ARM/m68k probes;
current startup/ownership documentation. No public feature activation.
This is an acceptance map, not a claim of final acceptance before candidate
native execution, owner review and four exact-head CI workflows are recorded.
